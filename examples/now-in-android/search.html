Search Module

← App map · Search topics and news as you type, with recent-search chips; opened from the top app bar's search icon.

What it does

Opened from the search icon in the top app bar (navigator.navigate(SearchNavKey)), not a bottom tab. The result state is gated two ways before a query ever runs a search: SearchNotReady while the full-text-search table hasn't been populated yet (fewer than 1 indexed item), then EmptyQuery while the typed query is under 2 characters — only past both does typing actually search topics and news live, one FullTextSearch query per keystroke via GetSearchContentsUseCase. A separate RecentSearchQueriesUiState lists up to the most recent searches as tappable chips while the query box is otherwise empty; explicitly triggering a search (the IME's search action, not just typing) saves it to that list, and a trash icon clears the whole history.
