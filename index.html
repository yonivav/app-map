App Map

Your app's architecture as UML you can click down to the code — and back.

Open the live example GitHub

An Agent Skill for Claude Code · Cursor · Codex · Gemini CLI · Copilot

  • Grounded in the code

    Diagrams start from what each class really builds and calls, and every name is checked against the source.

  • Both directions

    Any box, member or arrow opens its code. Any class or file finds every diagram that draws it.

  • Shows the real UI

    A simulator run crops each page and widget, so a popup shows how it looks next to how it's written.

  • Stays current

    Markdown in your repo, rebuilt in milliseconds. app-map changes and a CI check keep it in step with the code.

Install

For any agent that reads Agent Skills:

git clone https://github.com/yonivav/app-map ~/.app-map
cd your-app && ~/.app-map/install.sh

Or as a Claude Code plugin: /plugin marketplace add yonivav/app-map. Then ask your agent to build an app map of this repo. Full guide →
